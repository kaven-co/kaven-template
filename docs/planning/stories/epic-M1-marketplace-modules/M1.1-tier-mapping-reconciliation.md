# M1.1 — Reconciliar tier mapping nos module.json

> **Epic:** M1 (Marketplace Modules) | **Agent:** @dev (Bolt)
> **Priority:** P0 — baseline de tudo que vem depois. Sem isso, os outros módulos saem com tier errado.
> **Depends on:** nada
> **Blocks:** todas as outras stories do epic

---

## Contexto

O pricing migrou para `Starter / Builder / Pro` em 2026-04-17. Os `module.json` existentes usam
valores de tier que não refletem esse modelo:
- `payments`: `"tier": "pro"` — ERRADO (deve ser Builder+)
- `auth-social`: `"tier": "starter"` — ERRADO (deve ser Builder+)
- `storage`: `"tier": "starter"` — ERRADO (deve ser Builder+)
- `analytics`: `"tier": "free"` — ERRADO (deve ser Builder+)

Além disso, não existe um enum formal de tiers documentado como fonte de verdade para o campo `tier`
nos `module.json`. Esta story define o enum e atualiza todos os arquivos.

## User Story

**Como** usuário do CLI fazendo `kaven module install {slug}`,
**Quero** que o módulo mostre claramente qual tier é necessário,
**Para que** eu saiba antes de tentar instalar se preciso fazer upgrade.

## Acceptance Criteria

- [ ] Enum de tiers definido e documentado: `starter | builder | pro | enterprise`
- [ ] `modules/payments/module.json` → `"tier": "builder"`
- [ ] `modules/auth-social/module.json` → `"tier": "builder"`
- [ ] `modules/storage/module.json` → `"tier": "builder"`
- [ ] `modules/analytics/module.json` → `"tier": "builder"`
- [ ] `modules/payments-WRONG-DELETE/` → DELETADO (diretório órfão)
- [ ] `docs/planning/stories/epic-M1-marketplace-modules/MODULE-TIER-REFERENCE.md` criado com tabela completa de todos os módulos planejados e seus tiers
- [ ] Nenhum teste quebrado (module.json é metadata — não afeta runtime)

## Mapeamento Completo de Tiers (Opção A aprovada)

### starter — incluso no core, não é módulo instalável
> Auth, tenants, RBAC, email, files, notifications, spaces, audit, security, observability

### builder — Builder $99+
| Slug | Nome |
|------|------|
| `payments` | Stripe Payments |
| `auth-social` | Social Auth (GitHub, Google) |
| `storage` | S3/R2/GCS Cloud Storage |
| `analytics` | Analytics Dashboard |
| `email-templates` | Email Templates |

### pro — Pro $199+
| Slug | Nome |
|------|------|
| `advanced-rbac` | Advanced RBAC + SCIM |
| `i18n` | Internationalization |
| `blog` | Blog Engine (MDX) |
| `ai-studio` | AI Studio (AIOS integration) |
| `email-marketing` | Email Marketing |
| `pagubit-pix` | PIX Payments (BR) |
| `export` | Data Export (CSV/PDF/JSON) |
| `theme-builder` | Theme Builder |
| `marketplace-sdk` | Marketplace SDK |

### enterprise — Enterprise only
| Slug | Nome |
|------|------|
| `white-label` | White Label |
| `sso-saml` | SSO/SAML 2.0 |
| `soc2-toolkit` | SOC2 Toolkit |
